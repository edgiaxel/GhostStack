# Kiro IDE screenshots

Put screenshots here. They are the only Kiro evidence the repository cannot generate by itself, because only the IDE shows them. Everything else is produced by the hooks and `npm run evidence` (see `docs/KIRO-USAGE.md` section 5).

Use these file names so the write-up can link them. Skip any you cannot get.

| File | What it shows | When |
|---|---|---|
| `01-agent-picker.png` | The agent picker open with `orchestrator`, `slice-builder`, `reviewer` | Next session start |
| `02-spec-review.png` | A spec phase (requirements, design or tasks) open for review, ideally with comments | First M2.x spec |
| `03-spec-tasks-done.png` | A spec task list with tasks checked off by Kiro | After the first spec run |
| `04-hook-card.png` | A hook card in the IDE: `guard-writes` blocking, or `typecheck-on-stop` reporting | First time one appears |
| `05-property-test-failure.png` | A property test failing with its shrunk counterexample | If one fails; optional |

Before adding a file, check it shows no tokens, personal email addresses or paths you do not want public.
