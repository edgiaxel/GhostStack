# M3.2 Providers brief
Spec: `.kiro/specs/m3-2-ai-providers/requirements.md`. Scope: `docs/MILESTONE.md` M3.2. Imports `shared-contracts` only. Uses `fetch`, `AbortSignal`, `setTimeout`.
Delivers demo (rule-based, offline, deterministic: quiz question card with three answers branching to a result card; recipe card with an ingredients list and add-item button), Ollama (`/api/chat` with `format`, `/api/tags`, default `http://127.0.0.1:11434`, local), OpenAI-compatible (`/chat/completions`, `/models`, JSON schema or JSON mode by capability, one bounded repair retry, 401/429/network/schema normalization, honor `Retry-After`). One module owns the system prompt and `PLAN_JSON_SCHEMA`; the allowed command list comes from `AI_ALLOWED_COMMAND_TYPES`. No fallback between providers. The key never appears in a thrown error, message, log or snapshot. Prompt text inside Stack content must not widen the allowlist.
Shared contract test suite run against all three adapters. Mock servers are local `http` servers inside tests.
