# M3.1 AI core brief
Spec: `.kiro/specs/m3-1-ai-core/requirements.md`. Scope and exit criteria: `docs/MILESTONE.md` M3.1. Allowed imports: `shared-contracts`, `domain`, `behavior`. No React, DOM, `fetch`.
Delivers `parsePlan` (schema, allowlist, 50 steps, 64 kB, duplicate step ids, unknown dependsOn, cycles; code `INVALID_AI_PLAN`), `dryRunPlan` (deep copy, dependency order, `applyCommand`, `validateStack`; never mutates input), `summarizePlan` (per-Card plain sentences), `buildContext` (scope, character budget, deterministic truncation, no asset bytes or data URLs), `runTransaction(session, plan, { checkpoints, onProgress, signal, now, newId, inject? })` (checkpoint `Before AI: <summary>`, dry run, `session.restore`, cancel before commit, failure injection), `revertOperation`, `normalizeProviderError` (401, 429 with `Retry-After`, 5xx, network, bad JSON), `getRegisteredActions`.
Properties: dry run never mutates input; a passing dry run yields a valid Stack; a failed transaction leaves the Stack deep-equal; apply then revert equals the original; `parsePlan` never throws; `.gsp` export/import round trip of a planned Stack (use `@ghoststack/project-format` in tests only, report the devDependency need).
